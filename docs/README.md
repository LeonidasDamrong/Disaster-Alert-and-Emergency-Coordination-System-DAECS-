# DAECS – Disaster Alert and Emergency Coordination System

## 📌 Overview
A cloud-based disaster management system designed to support real-time SOS tracking and emergency coordination.

## 🚀 Features (Completed)
- SOS reporting and case tracking module
- Backend API development using ASP.NET Core
- Database design and implementation
- Resource management system

## 🚧 In Progress
- Real-time updates using SignalR
- Mobile app integration (Flutter)
- Deployment and optimization on Microsoft Azure

## 🛠️ Tech Stack
- ASP.NET Core
- Microsoft Azure
- MySQL
- Flutter (ongoing)
